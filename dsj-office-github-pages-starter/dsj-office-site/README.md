# DSJ Office — test website

A responsive static website concept for DSJ Office built with plain HTML and CSS. No build tools, framework, or JavaScript are required.

## Files
- `index.html` — page structure and copy
- `styles.css` — colors, layout, responsive styling
- `assets/dsj-office-banner.png` — cropped original DSJ Office banner from the screenshot provided for this project

## Preview locally
Open `index.html` in a web browser. Keep `styles.css` and the `assets` folder alongside it.

## Publish with GitHub Pages
1. Create a repository on GitHub.
2. Upload `index.html`, `styles.css`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for the published site URL to appear in the Pages settings.

Official guide: https://docs.github.com/en/pages/quickstart

## Before publishing publicly
- This is a visual test concept, not a verified final business website.
- Confirm all service descriptions, credentials, copyright details, and contact information.
- The contact buttons use `mailto:` and `tel:` links; they do not submit a form or collect information.
- Review the site on a phone and desktop.
- Ensure you have permission to use all brand images and assets.
